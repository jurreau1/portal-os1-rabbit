# MAXVERSE Acceptance Plan

## A. Portal Tests

- Portal loads
- Sidebar navigation works
- Mobile navigation works
- Theme switching works
- Command palette opens

## B. Command Tests

- Ctrl+K opens palette
- Escape closes palette
- Enter executes command
- History persists
- Fuzzy matching works

## C. Identity Tests

- User profile loads
- Preferences persist
- Library loads
- Logout works

## D. Marketplace Tests

- Browse products
- Search products
- Creator pages open
- Product install flow works

## E. Creator Tests

- Create project
- Save project
- Publish project
- Edit project
- Remove project

## F. World Tests

### Nexus

- Spawn works
- Teleports work
- Return to portal works

### Districts

- Games loads
- Apps loads
- Media loads
- Research loads
- Creator loads
- Marketplace loads
- Community loads
- AI loads

## G. Performance Tests

### Desktop

- 60 FPS target

### Tablet

- 45 FPS target

### Mobile

- 30 FPS target

## H. Release Gate

MAXVERSE is release-ready only when:

- All phases A–F pass
- No TypeScript errors
- No broken imports
- No console errors
- Responsive on mobile/tablet/desktop
- Command layer functions globally
- World and portal interoperate
- Registry-driven architecture is maintained

## Final Release Definition

A user can:

1. Create Account
2. Enter Portal
3. Use Command System
4. Launch Apps
5. Play Games
6. Research Information
7. Create Content
8. Publish Projects
9. Browse Marketplace
10. Enter 3D World
11. Navigate Districts
12. Interact with AI
13. Return to Portal

using a single MAXVERSE ecosystem.
